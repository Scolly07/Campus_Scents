# Website testing checklist

Use this checklist before submitting. Mark each item only after testing it.

- [ ] Home page opens at `index.php`
- [ ] Logo links to Home from all pages
- [ ] Home, About and Contact links work
- [ ] Navigation hover and current-page styles are visible
- [ ] Mobile menu opens and closes on a narrow screen
- [ ] Layout works at desktop, tablet and phone widths
- [ ] Fragrance filters show the correct cards
- [ ] Scent suggestion changes with the selected mood
- [ ] EN / ZU button switches marked Home-page text
- [ ] Contact form rejects an empty name
- [ ] Contact form rejects an invalid email address
- [ ] Contact form rejects a message shorter than 10 characters
- [ ] Valid contact form shows the demo confirmation
- [ ] Footer includes business name, location, contact details, social links and copyright
- [ ] Replace demo email and phone details with approved details
- [ ] Check external links and correct any that do not meet lecturer requirements
- [ ] Take screenshots for the project report
