# Campus Scents website project

A responsive student fragrance website built with PHP, HTML, CSS and JavaScript.

## Files
- `index.php` — Home page
- `about.php` — About page
- `contact.php` — Contact page with client- and server-side validation
- `includes/header.php` — shared navigation, page metadata and stylesheet/script links
- `includes/footer.php` — shared footer
- `assets/style.css` — responsive design and style guide
- `assets/script.js` — mobile navigation, fragrance filters, scent suggestion and English/isiZulu text switch

## Run locally
1. Install PHP 8 or later.
2. Open a terminal in this folder.
3. Run: `php -S localhost:8000`
4. Visit `http://localhost:8000` in a browser.

PHP must be used; opening the `.php` files directly as local files will not run the server-side code.

## Important limitation
The contact form validates input and displays a confirmation for demonstration, but it does not send email. Email delivery requires mail-server configuration or an approved backend service. Social links currently lead to the platforms' general homepages and should be replaced with your actual profiles.
